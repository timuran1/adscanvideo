How to share a video analysis report: email, Word and PDF

A completed analysis is the beginning of a handoff. Choose a format your reviewer can use, preserve the source version, and make unresolved observations visible before you send it.

Updated October 21, 2026 · 9 min read

For a creative strategist or small agency, the practical question is often simple: should I send a link, an editable document, or a PDF? Each solves a different problem. An email link is convenient for returning to one report. Word supports an editable working document. PDF is useful for inspecting a particular exported layout. None of these formats confirms that the analysis is correct.

Choose the delivery method before exporting

  • Read on screen: one daily analysis is free without signup, up to 10 minutes and 200 MB. A completed free report remains readable without an email gate.
  • Email a report link: the optional report email sends access to that one report for seven days. Anyone holding that link can read it. It is not a downloadable PDF attachment or an account login.
  • Free Copy, Word or PDF: verify your email account to use watermarked free exports. Inspect the actual output before sharing it.
  • Clean paid deliverable: one credit removes the watermark from an eligible existing free report without rerunning the analysis. Paid analyses include clean exports.

Decide who needs access, then choose the file

Start with the recipient's job. A reviewer who only needs to read one report has a different need from an editor who must revise a brief. Keep access and file format as separate decisions.

A worked handoff check using a real public report

Open the product-demo source and its actual Ad intelligence report. It is licensed behind-the-scenes footage, not a customer case study. The generated report describes a ten-second sequence; the source file is approximately 11.07 seconds. Preserve that discrepancy in the handoff instead of shortening the source to make the report appear exact.

  1. Identify the source. Record Pexels clip 38161399 by Ali Jafar and the sample page. The original file is 1080 × 1920 and has no audio stream. A music track added to a social adaptation does not become evidence from the original.
  2. Keep the report's qualification. Its evaluation says effectiveness cannot be determined from the footage alone. Include that qualification beside any proposed revision. The report is not campaign-performance evidence.
  3. Write a bounded editorial next step. For example: verify the product label from an authorized source before drafting a benefit caption. Mark that as an editorial task; the footage does not establish the exact product identity or a measured benefit.
  4. Leave unperformed checks open. Reading the sample page is not proof that a Word or PDF export was downloaded and inspected. Until you open the actual deliverable, keep its layout and watermark checks marked Not reviewed.

A report email and a sign in email do different jobs

Email me this report gives the recipient a temporary private link to a single report. Treat it like a bearer link: forwarding it also forwards access. Do not use it when the recipient must be individually authenticated or when your client's sharing policy prohibits this kind of link.

A sign in link verifies your email account. The login link expires after 15 minutes and requires the confirmation action on the login page. If you are connecting a report created before signing in, open the email link in the same browser you used for that report. Opening it in a different browser does not automatically attach unverified anonymous reports from the original browser.

Requesting a report email or signing in does not by itself subscribe someone to promotional emails. Marketing consent is a separate optional choice. Use Email preferences to unsubscribe from those messages. A requested report or sign in email has a different purpose.

Prepare a reviewed document, not a screenshot of success

  1. Keep the source reference. Record the filename, version and permission to analyze or share it. A public ad is not automatically licensed for republication.
  2. Replay important observations. Use the report's candidate timestamps to find the moment, then check the source. Audio claims need an audio replay. A still image cannot verify speech or an audible beat.
  3. Label editorial additions. Separate a generated observation from a human interpretation or proposed edit. Keep Unclear and Not reviewed visible when evidence is missing.
  4. Choose and inspect the export. Open the actual Word or PDF file you intend to send. Check the title, first and last observation, page breaks and watermark state. Check every PDF page if the document spans several pages.
  5. Record the sent version. Save the exact filename and handoff date. If you revise the report, issue a new version and say what changed.

When to use Copy, Word or PDF

Copy is useful when you need an excerpt in an existing brief. Keep the source range and qualification beside it rather than copying only a confident sentence. Free copied output includes a watermark notice.

Word is useful when the recipient will edit the working document. AdScanVideo's Word download uses a .doc filename. Check it in the recipient's intended editor before treating it as a final deliverable; do not assume it is a native .docx file.

PDF is useful for checking the exported page layout. Free PDF exports carry an AdScanVideo watermark on each page; paid exports omit that watermark. A clean PDF does not establish that the underlying observations have been verified, and a PDF is not a restriction on forwarding the file.

If you move the text into Google Docs for collaboration, Google's help documents downloading a copy in a chosen file type. That creates a separate file. Reopen the new download and check its layout; do not assume it matches the original export exactly.

Fix the right problem when sharing fails

  • The sign in link expired: request a fresh login link and confirm it within 15 minutes. Do not forward a login link to a client.
  • The report email link expired: its seven day access window is separate from your login session. Return to a report you can still access and request another report email if appropriate.
  • The file still has a watermark: confirm you are signed into the account with paid access and that this report's clean exports are unlocked. Do not rerun the analysis merely to troubleshoot an export.
  • The last PDF page is incomplete: reopen the actual downloaded file and compare it with the on screen report. Preserve the report and contact support with the symptom, rather than including a private access link in a public post.

Frequently asked questions

Do I need an email address to read my first free report?

No. The daily free report stays readable on screen. Email capture is optional; verified email login is used for free watermarked exports and before checkout.

Does one credit buy a second analysis when I unlock an existing report?

No. When used for an export unlock, the credit removes the watermark for that existing report without running another analysis. A new paid analysis is a separate use of a credit.

Can I share the report email link with a client?

Anyone holding the link can read that one report during its seven day window. Confirm that this matches your client's permission and confidentiality requirements before forwarding it.

Will a paid export remove uncertainty from the report?

No. Payment changes export access and watermark state. You still need to verify important observations against the original video.

Does receiving a report email create a marketing subscription?

No. Requested report delivery and account verification are separate from marketing consent. Promotional emails require the separate opt-in and confirmation; Email preferences provides the unsubscribe control.
