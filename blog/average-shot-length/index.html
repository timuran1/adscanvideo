How to measure average shot length without miscounting cuts

Average shot length is simple arithmetic. The hard part is the shot count. Confirm every cut against the source first, then calculate the mean, the median and cuts per minute.

Published November 25, 2026 · 6 min read

The same video produced three answers. We ran ffmpeg scene detection on one of our own 24-second Shorts. At three thresholds it reported 1, 2 and 4 cuts, which gives an average shot length of 12, 8 or 4.8 seconds. Only the last matches the project file the video was rendered from.

The formula

Film researcher Barry Salt defines average shot length (ASL) as the length of a film in seconds divided by the number of shots in it. The same calculation works for an ad, a Short or a tutorial:

shots                 = confirmed cuts + 1
average shot length   = running time (s) / shots
median shot length    = middle value of the sorted shot durations
cuts per minute       = confirmed cuts / running time (s) x 60

The average is a mean, so one long take pulls it up. Cinemetrics reports the median alongside it for that reason: half the shots are longer than the median and half are shorter. When a video mixes very quick cuts with one long hold, quote both numbers.

Why the count goes wrong

Every pacing number depends on how many cuts you counted. Two shortcuts produce wrong counts:

  • Treating a detector's output as final. ffmpeg's select filter gives each frame a scene score between 0 and 1. Its documentation says comparing that score against a value between 0.3 and 0.5 is "generally a sane choice". A sane default is still a guess about your footage.
  • Treating report rows as shots. An AI shot breakdown describes time ranges. Several rows can describe one continuous shot.

Our November 13 Short is 24.0 seconds at 30 frames per second. Its project file places hard cuts at frames 90, 240, 390 and 540, which is 3, 8, 13 and 18 seconds. At a 0.3 threshold, ffmpeg flagged exactly those four times.

A second Short of ours, from November 8, has the same length and also has four hard cuts, at 3, 7, 13 and 18 seconds according to its project file. Its scenes share the same cream background and a similar black-text layout, so the frame-to-frame change at a cut is small.

Test 3: report rows are not shots

Our public animated cat shot breakdown lists nine timestamped rows for an 8.64-second clip. Dividing gives 0.96 seconds per row, which looks like very fast cutting. It is not a shot length. The last four rows describe the same kitchen action, and the sample page itself notes that near-identical cooking frames stayed separate because the visuals kept changing. The source file is not hosted there, so we have not counted its real cuts. Use rows as a map of where to look, then confirm cuts in the source.

A repeatable workflow

  1. Collect candidates. Use the report's timestamps, a scene detector, or both. To list detector candidates, run: 
    ffmpeg -i your-video.mp4 -vf "select='gt(scene,0.3)',showinfo" -an -f null - 2>&1 | grep -o "pts_time:[0-9.]*"
    Run it again at a lower value such as 0.1 and compare the lists.
  2. Replay each candidate. Step a few frames either side. Mark it a cut only when the shot actually changes; a fast pan, a flash or a text change inside one shot is not a cut.
  3. Look between candidates. Scrub any long gap for a cut the detector missed, especially between similar-looking shots.
  4. Log confirmed cuts. Record each time and how you confirmed it in the free shot length log (CSV).
  5. Calculate. Use the running time and confirmed cuts for the mean, the median and cuts per minute. Note the frame rate and the cut count beside the result so others can check it.

Where an AI shot breakdown fits

A shot breakdown describes what happens in each range: framing, action, setting and camera movement. That makes candidate cuts faster to find and explains what changed at each one. It does not certify a frame-exact boundary, so the confirmed-cut step stays manual. Frequently asked questions

How do you calculate average shot length?

Divide the video's running time in seconds by the number of shots. The number of shots is the number of confirmed cuts plus one. A 24-second video with 4 cuts has 5 shots and an average shot length of 4.8 seconds.

What is the difference between average and median shot length?

Average shot length is the mean of all shot durations. The median is the middle duration when the shots are sorted, so a few very long shots move it less. Report both when shot lengths vary a lot.

Can ffmpeg scene detection count cuts automatically?

It can list candidate cuts, but the count depends on the threshold. In our test, the documented 0.3 threshold found 1 of 4 real cuts in one Short and all 4 in another. Replay every candidate before you use the count.

Is each row of an AI shot breakdown one shot?

No. A row is a time range the report describes. Several rows can describe one continuous shot, and one row can cover a quick cut. Confirm the cut points against the source before calculating pacing.
